# AG Suitcases Collection

Static storefront for GitHub Pages.

## Customer flow
Browse products → review price/colour/details → check availability on WhatsApp.

The cart is a selection tool; it does not process payment or create a backend order.

## Before launch
- Confirm all prices and colour availability against current stock.
- Confirm AG's delivery, exchange and returns terms.
- Confirm WhatsApp number and social links.
- Test WhatsApp handoff on Android/iPhone.
- Publish `sitemap.xml` and submit it to Google Search Console.
- Replace placeholder/temporary photography with final AG product photography where available.
